# Thesis Reproducibility Package

Code, configuration, and data manifests for every figure and simulation in the thesis. Python environment: `requirements.txt` (pip freeze).
GEOS builds: `simulation/GEOS_VERSIONS.md`.

## Layout

- `notebooks/`: all analysis notebooks plus the helper modules they import
  (`hdf5_tools`, `compare_tools`, `mesh_tools`, `pvd_tools`, `GEOS*` mesh classes).
  Run notebooks from inside this folder: the imports AND all data paths are
  relative to it (`../inputs`, `../outputs`, `../data`; figures land in
  `../figures`, created on demand).
- `simulation/`: deck generator (`kgd_xml_gen.py`), HFTS-2 property-table builder
  (`buildInputTables_hfts2.py`), NERSC scaling job scripts, log-timing extractor,
  and the GEOS version pins.
- `data/`: small derived data: `b6s_stress_profile.csv` (mechanical earth model,
  generated by `compute_stress_profile.ipynb`), `strong.csv` / `weak.csv`
  (scaling timings, generated by `extract_scaling_times.py` from the NERSC logs).

## Data availability

The large data folders are NOT in this repository; they are archived on Zenodo
(DOI: TO-BE-ADDED after the Zenodo record is published) as four tar files:
`hss_field_data.tar` (restores `inputs/field_data/`), `hss_outputs_kgd_spacing.tar`,
`hss_outputs_kgd_injection.tar`, and `hss_outputs_heterogeneous.tar` (restore
`outputs/`). Extract each at the repository root and the notebooks run as-is.
SHA-256 checksums and a manifest accompany the archives.

The HFTS-2 field data are curated subsets of the public DOE/NETL EDX archives:
well data at https://edx.netl.doe.gov/dataset/individual-test-well-data and
fiber-optic data at https://edx.netl.doe.gov/dataset/fiber-optic-data.

## Packaged data

- `inputs/kgd/`, `inputs/heterogeneous/`: GEOS deck XMLs (incl. `tables/`, `tables_hfts2/`).
- `inputs/field_data/well_logs/`: the curated survey/rock-props subset used by
  `plot_well_trajectories` and `compute_stress_profile` (mirrors `research/HFTS-2/B*`).
- `inputs/field_data/well_data/`: the raw wireline subset used by
  `wireline_logs_brittleness`: every `.las` plus the deviation-survey spreadsheets for
  the five Boxwood wells.
- `inputs/field_data/fracture_maps/`: the two OptaSense fracture-map workbooks.
- `inputs/field_data/fiber/`: the used LF-DAS windows.
- `outputs/heterogeneous/`, `outputs/kgd_spacing/`, `outputs/kgd_injection/`: the GEOS
  time-history HDF5 outputs needed by the analysis notebooks.

## Simulation manifest

Unmodified upstream copies of the KGD example decks are archived in
`simulation/upstream_geos_examples/` (see its PROVENANCE.md). All decks descend from examples distributed with GEOS (`inputFiles/hydraulicFracturing`
in the GEOS repository, https://github.com/GEOS-DEV/GEOS/tree/develop/inputFiles/hydraulicFracturing):
the 2D family from `kgdToughnessDominated`, the 3D family from
the heterogeneous in-situ stress benchmark. The benchmark property tables
(`inputs/heterogeneous/tables/`, incl. `buildInputTables.py`) are byte-identical copies of the
upstream `tables/` folder. Modifications (meshes, sources, property
tables, output collections) are contained in the packaged deck files.

| Case family | Decks (inputs/) | Outputs used (outputs/) |
|---|---|---|
| 2D KGD single (base) | `kgd/…_2_const_grid_single` | `kgd_spacing/…_single_rerun/{timeHistory, _strain}.hdf5` |
| 2D KGD spacing d=8–24 m | `kgd/…_2_const_grid_{8..24}` | `kgd_spacing/…_{8..24}_rerun/…` |
| 2D KGD injection Q0…Q0/16 | `kgd/…_inj_{reg..sixtineth}_150t` | `kgd_injection/…_150t/…` |
| 3D new/pre-existing ×2 (benchmark, HFTS-2) | `heterogeneous/…_frac_{20..23}` (+`tables`, `tables_hfts2`) | `heterogeneous/frac_{20..23}/{timeHistory, _fiber, _strain}.hdf5` |
| Scaling (strong/weak) | timing decks generated by `simulation/*_scaling_kgd.sh` | `data/strong.csv`, `data/weak.csv` (run on NERSC Perlmutter) |

GEOS commits for the local and NERSC builds are in `simulation/GEOS_VERSIONS.md`.
